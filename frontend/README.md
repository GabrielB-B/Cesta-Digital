# Frontend Cesta Digital

Frontend oficial do Cesta Digital em React + Vite.

## Fluxo atual

- entrada principal: `src/main.tsx`
- app principal: `src/App.tsx`
- layout autenticado: `src/layouts/AppLayout.tsx`
- cliente HTTP oficial: `src/api/client.ts`

## Comandos

```powershell
npm install
npm run dev
npm run lint
npm run build
```

## Observação

Os arquivos legados de rota/layout antigo foram removidos para manter apenas a estrutura em uso no produto atual.

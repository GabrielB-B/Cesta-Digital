## Regra de fidelidade

As referências por tela definem linguagem, composição, densidade, paleta e
padrões de interação de cada área. A baseline geral cobre apenas lacunas. Dados,
métricas e itens de menu ilustrativos não autorizam novas rotas, permissões,
APIs ou regras de negócio.

Para toda mudança visual, comparar:

1. referência específica da tela e baseline geral;
2. estado anterior da tela;
3. implementação proposta em 390x844 e 1440x900;
4. 768x1024 quando a composição mudar materialmente.

Registrar diferenças deliberadas e aguardar aprovação de Gabriel antes de
avançar para o próximo marco visual.

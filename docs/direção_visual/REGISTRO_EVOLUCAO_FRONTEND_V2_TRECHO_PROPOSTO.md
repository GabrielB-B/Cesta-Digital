# Registro de evolução do Frontend V2

registro de evolução, durante o marco `V2-00`:

| 18/08/2026 | Aprovação da identidade Frontend V2 | A direção visual clean, mobile-first e desktop responsiva passa a ser a identidade vigente do frontend, preservando o símbolo Cesta Digital. A antiga linguagem dark premium deixa de orientar novas telas. Ficam proibidos gradientes decorativos, glow, glassmorphism, faixas coloridas e excesso de cards. A implementação será incremental, preservando rotas, RBAC, contratos de API e comportamentos funcionais, conforme `docs/direção_visual/PLANO_ENGENHARIA_FRONTEND_V2_CESTA_DIGITAL.md`. |

A seção de direção visual também foi atualizada para referenciar o novo plano e
explicitar que o mockup é baseline estética e de interação, não contrato de
novas funcionalidades.
